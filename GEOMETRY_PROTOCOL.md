# Geometry and shear gate: protocol fixed before measurement

7 October 2026. This extends the existing VMN research probe. It is a small
reservoir experiment and a response-reconstruction test, with no competitive
AI-layer claim. VMNClaude is an inspiration and remains read-only.

## Matched dynamics

Eight planar oscillator states give 16 real state coordinates. Let V be the
point-vortex velocity with fixed circulations and denominator r² + δ². Let p
be shared anchor positions. Local units obey a cubic Stuart–Landau equation
with heterogeneous frequencies and decay rates. Their coupling is

$$
C_\eta(q)=\begin{cases}
\kappa D V(p)q,&\eta=0,\\
\dfrac{\kappa}{\eta}[V(p+\eta q)-V(p)],&\eta>0.
\end{cases}
$$

Thus fixed and moving geometry have the same state dimension, input,
coupling scale and linearization at rest. Geometry changes only higher-order
terms. This is a designed hybrid model, not a fluid simulation or a derived
biological neuron. The regularized kernel contains rotation as well as strain.

Compare geometry η = 0 and 1, each with shear β = 0 and 2. Include a fixed
linear oscillator control with the cubic term disabled. Use δ = 0.15;
normalize κ so the vortex Jacobian at the anchors has spectral norm 0.35.
Frequencies span 1 to 1.7; unit decay rates span 0.04 to 0.20. Inputs have
strength 0.15 along a fixed random unit vector. Anchors are a jittered grid
with spacing 1.5, generated by the existing positions helper.

The critical parameter is computed from the *coupled* rest Jacobian:
μ_c = -max Re eig(A at μ = 0). Record the critical eigenvalues; do not assume
the crossing is a Hopf bifurcation. Sweep μ - μ_c = -0.30, -0.10, -0.03,
+0.03, +0.10. The linear control uses only the three stable offsets.

## Delayed-input memory

- Four paired layout/input seeds, 20261007 through 20261010.
- Uniform independent scalar inputs in [-1, 1], held constant per sample.
- Sample duration 0.25; RK4 with two substeps. Check refinement separately.
- Separate train, validation and test trajectories, each starting at rest.
- Washout 256 samples, then 1200 training, 400 validation and 800 test samples.
- Targets: Legendre orders 1, 2 and 3 of inputs at lags 1, 2, 4, 8, 16, 32.
- One affine readout per configuration, 17 × 18 coefficients. Standardization
  uses training states only. Ridge penalties 1e-6, 1e-4, 1e-2 and 1 are
  selected by validation error normalized by training target variance.
- Select the operating offset using validation mean R² for orders 2 and 3.
  Test data never selects a ridge penalty or operating point.
- Primary geometry gate: moving versus fixed geometry at β = 2 must improve
  mean test nonlinear R² by at least 0.02 and win on at least three of four
  paired seeds. Apply the same criterion to shear on versus off within each
  geometry. Report signed R², correlation-based memory capacity and long-lag
  scores. Record failures without changing the protocol.

These tests measure memory of a driven sequence, not learning retained in
weights across tasks. The reservoir and readout budgets are matched.

## Two histories, same later probes

Use seed 20261007 at coupled offset -0.03 for the four nonlinear variants.
Prepare a baseline with 256 random input samples. Make a position-state
impulse of magnitude 0.07 in each cardinal direction at each of eight units,
then allow one unit of unforced evolution. Both histories subsequently
receive the same zero input and all 16 infinitesimal state probes.

Observe the tangent at 16 evenly spaced times for each horizon 0.5, 2 and 6.
Report baseline and update participation ranks, 95%-energy ranks and relative
update magnitude. Numerical matrix rank and spectral concentration remain
distinct quantities.

Fit a fixed POD dictionary of flattened updates using only sites 0–4; sites
5–7 are held out. Choose its component count for 95% training energy. Its
coefficients come from the true update, making it an optimistic bound.

Compare a state decoder that retains the largest 1, 2 or 4 planar difference
blocks at probe time, relative to the shared baseline. Store each block index
and its two coordinates, then regenerate the response from the known model.
The encoder uses current state differences, not past event labels. Evaluate
held-out reconstruction and actual later probe outputs. This decoder follows
the model's geometry instead of fitting a matrix basis at particular sites.

Count the shared baseline, model, POD matrices, per-event code and regeneration
cost separately. A sparse incremental event code does not establish a total
storage or speed saving over retaining the full 16-coordinate state.

## Mathematical and numerical checks

Verify regularized and hybrid Jacobians by central differences, the common
rest linearization, integration refinement, the fixed linear negative control,
and tangent responses using finite-amplitude probes. Derive and check the exact
radial-kick phase shift and relaxed Jacobian-change norm. Record every source
hash, seed, threshold and split in a machine-readable receipt. Old VMN checks
must continue to pass.
